# PROJECT OVERVIEW
This project focuses on performing Exploratory Data Analysis (EDA) on a dataset containing 50,000 cancer patient records collected across multiple countries between 2015 and 2024. Utilizing Python along with powerful data manipulation and visualization libraries such as Pandas, NumPy, Seaborn, and Matplotlib, the project explores patient demographics, genetic and lifestyle risk factors, environmental exposure, cancer types and stages, treatment costs, survival years, and severity scores.
The analysis aims to identify trends, uncover patterns, and investigate relationships between risk factors and cancer severity, early-stage diagnosis rates, treatment costs, and patient survival outcomes. It also examines variations across countries, age groups, and cancer stages to explore potential healthcare disparities. The goal is to transform raw patient data into meaningful insights that can support further research, improve understanding of cancer care outcomes, and inform data-driven healthcare decisions.
